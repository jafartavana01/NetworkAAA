Pulls in the dictionaries shipped with tac_plus-ng (Cisco, Cisco-ASA, Fortinet, PaloAlto, Juniper, Microsoft, APC, MikroTik) by reference rather than copying them.
Transport
UDP only. tac_plus-ng also documents TCP, DTLS and TLS (RadSec), but their listener syntax wasn't present in the sample configuration this was built against — so it isn't offered rather than guessed. Emitting a directive the daemon rejects would take TACACS+ down with it.

Test the RADIUS Server

Sends a real Access-Request to the local listener using a device's stored shared secret. A NAS counter showing requests with zero responses can mean the listener is down, the client isn't defined, or the secret doesn't match — this tells them apart.
