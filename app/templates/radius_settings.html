RADIUS Settings

RADIUS listeners for devices that don't speak TACACS+. The same daemon, users, groups and policies serve both protocols.

⚠ Enabling RADIUS opens new UDP listeners on this server. Nothing changes on the daemon until you compile and apply the configuration from Configuration — the same workflow every other change uses.
1812 and 1813 are the standard RADIUS ports. Ports below 1025 aren't offered — the daemon shouldn't need privileges it can do without.
Pulls in the dictionaries shipped with tac_plus-ng (Cisco, Cisco-ASA, Fortinet, PaloAlto, Juniper, Microsoft, APC, MikroTik) by reference rather than copying them.
Transport
UDP only. tac_plus-ng also documents TCP, DTLS and TLS (RadSec), but their listener syntax wasn't present in the sample configuration this was built against — so it isn't offered rather than guessed. Emitting a directive the daemon rejects would take TACACS+ down with it.
