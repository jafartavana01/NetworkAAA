Command Sets

Reusable, named permit/deny rule collections — a Policy references one or more Command Sets instead of duplicating rules. Manage which policies use a set, and view its usage before deleting it.

Denied commands always win — across every set a policy references, not just within one set. A broad permit ^show in one set and a specific deny ^show running-config in another still results in that one command being denied.

Patterns are regex, not wildcards. To match every "show" command, use ^show — not show*, which in regex means "sho" followed by zero-or-more "w" characters, not "show anything." A few common patterns: ^show (all show commands), ^configure terminal (entering config mode), ^reload$ (exactly the reload command, nothing after it).
