Scheduled Audits

A platform-owned SSH account NetworkAAA uses to audit every enabled device on its own, once a day, without a human logging in each time.

⚠ This account can reach every enabled device unattended — treat its password with the same care as a device's own TACACS+ shared secret. It is never displayed once saved. Restrict where it can actually be used to sign in by allow-listing this platform's own management IP on each device's own SSH access-list — NetworkAAA has no way to configure that restriction on a device itself, so it's on you to set it up there; use the field below to note that IP for your own reference.
Leave blank to keep the current password.
The polling loop checks every few minutes, so the actual run may start a few minutes after this time, not to the exact second.
